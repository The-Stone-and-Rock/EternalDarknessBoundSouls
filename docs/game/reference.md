## Controls, from StrategyWiki

A context action opens doors and climbs ladders. Target with one trigger, sprint with the other, which also cycle menu screens. Quick spells go on four directions of the D-pad and one button. Reload is held to fill revolvers and shotguns. The button pictures didn't come through in the text: `controls.cpp` has the real bindings.
